# 검증 범위

- 150개 고유 항목, 각 분류 30개.
- 한국어 150개 + 영어 120개 AI 음성 파일. 한글은 양쪽 모드에서 한국어 음성을 공유.
- 3개 PNG 스티커 시트의 실제 투명 채널 확인.
- Chrome 자동 검증: 태블릿 1280px / 휴대폰 390px·320px, 전체 탭과 페이지, 영어 전환과 오디오 재생.
- 가상 마이크로 녹음 → 저장 → 새로고침 → 가족 음성 재생, 언어별 분리, 삭제 검증.
- 녹음실 닫을 때 마이크 트랙 종료 확인.
- 인터넷 연결을 끊고 다시 열어 화면과 음성을 사용하는 오프라인 시나리오 검증.

갤럭시 실물 기기에서의 설치·마이크 음질·제조사별 권한 화면은 아직 직접 검증하지 않았습니다. 자동 녹음 검증에는 가상 마이크를 사용했습니다. 모든 음성의 청취 품질과 모든 실물 기기 조합을 검증했다는 의미는 아닙니다.
