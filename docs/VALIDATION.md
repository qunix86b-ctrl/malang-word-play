# 검증 범위

- 150개 고유 항목, 각 분류 30개.
- 한국어 150개 + 영어 120개 AI 음성 파일. 한글은 양쪽 모드에서 한국어 음성을 공유.
- 3개 PNG 스티커 시트의 실제 투명 채널 확인.
- Chrome 자동 검증: 태블릿 1280px / 휴대폰 390px·320px, 전체 탭과 페이지, 영어 전환과 오디오 재생.
- 가상 마이크로 녹음 → 저장 → 새로고침 → 가족 음성 재생, 언어별 분리, 삭제 검증.
- 녹음실 닫을 때 마이크 트랙 종료 확인.
- 인터넷 연결을 끊고 다시 열어 화면과 음성을 사용하는 오프라인 시나리오 검증.

갤럭시 실물 기기에서의 설치·마이크 음질·제조사별 권한 화면은 아직 직접 검증하지 않았습니다. 자동 녹음 검증에는 가상 마이크를 사용했습니다. 모든 음성의 청취 품질과 모든 실물 기기 조합을 검증했다는 의미는 아닙니다.

## v1.1.0 추가 검증

- 1280×800, 800×1280, 1024×768, 600×960, 960×600에서 30개 스티커가 스크롤 없이 한 화면에 들어오는지 확인. 찾기 놀이 안내가 있을 때도 동일하게 검증.
- 오답 뒤 동일 문제 유지, 정답 칭찬 및 다음 문제, 다시 듣기, 언어·탭·놀이 모드 전환 확인.
- 휴대폰에서 보이는 6개 중 출제, 오프라인 찾기 놀이 확인.
- 전체 단어를 한 번씩 출제한 뒤 반복하며 연속으로 같은 문제가 나오지 않는지 확인.
- 단어 음성 270개에 문제·피드백 274개를 추가, 총 544개 번들 음성 파일 확인.
- 데이터 테스트 7개, 브라우저 테스트 11개 통과.

## v1.2.0 추가 검증

- 칭찬 재생을 4.5초로 지연시켜도 재생 종료 전에는 다음 문제가 나오지 않는지 확인. 칭찬 중 다시 듣기 비활성화, 연속 그림 터치, 게임 종료 시 예약 취소도 확인.
- ABC·abc 각 26개, 영어 문자 이름 재생, 한·영 찾기 문제, 녹음실 목록 확인.
- 권한 요청만 한 뒤 모든 마이크 트랙이 종료되고 녹음이 저장되지 않는지 확인. 거부 시 안내와 재시도 버튼 표시 확인.
- 총 202개 항목 / 700개 음성 파일. 데이터 8개 + 브라우저 16개 테스트 통과.
- Android 마이크 권한 요청 및 앱 설정 연결 플러그인을 포함한 release 빌드 성공. 실제 갤럭시 설정 화면 조작은 미검증.

## v1.2.1 마이크 권한 수정

- Capacitor WebView의 AUDIO_CAPTURE 경로가 요구하는 RECORD_AUDIO / MODIFY_AUDIO_SETTINGS와 Android Manifest 선언을 대조. 기존 버전에는 MODIFY_AUDIO_SETTINGS가 빠져 있었음.
- 권한 허용 후 앱 복귀 시 상태 재조회 및 기존 차단 안내 숨김 검증.
- 권한은 허용됐지만 실제 녹음 연결이 실패하는 경우를 별도로 검증하여 반복 권한 요구 방지.
- 브라우저 테스트는 가상 마이크를 사용하며 실제 갤럭시 기기의 재현 확인을 대체하지 않음.
