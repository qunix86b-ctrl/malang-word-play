# 말랑말랑 단어놀이 v1.2.0

- **칭찬이 끝난 뒤 다음 문제:** 고정 시간으로 넘어가던 방식을 고쳐 음성의 실제 재생 종료를 기다립니다. 칭찬 중 그림이나 다시 듣기를 연속해서 눌러도 잘리지 않습니다.
- **ABC / abc 알파벳:** 대문자 A–Z와 소문자 a–z 각각 26개, 총 52개를 추가했습니다. 영어 발음 듣기, 한국어·영어 찾기 문제, 단어별 가족·아이 목소리 녹음을 지원합니다.
- **마이크 권한 도우미:** 녹음실에서 권한을 미리 요청할 수 있습니다. Android 앱은 앱 권한 설정으로 연결되며, 웹에서는 브라우저 권한 변경 방법을 보여줍니다. 권한 확인만 할 때는 녹음을 저장하지 않습니다.

총 7개 탭, 202개 항목, 단어·놀이 안내 음성 700개를 오프라인으로 제공합니다.

## 설치 / 업데이트

아래 `malang-word-play.apk`를 내려받아 설치하세요. **기존 앱을 삭제하지 않고 업데이트**하면 저장된 녹음을 유지할 수 있습니다. 같은 앱 ID와 같은 서명 키를 사용합니다.

[웹에서 사용하기](https://qunix86b-ctrl.github.io/malang-word-play/?v=1.2.0)

마이크 설정: **보호자 → 우리 목소리 녹음하기 → 마이크 권한 허용하기**. Android에서 이미 차단했다면 **앱 권한 설정 열기 → 권한 → 마이크 → 앱 사용 중에만 허용**을 선택하고 돌아오세요.

데이터 테스트 8개와 브라우저 테스트 16개, Android release 빌드 및 서명 확인을 수행했습니다. 갤럭시 실물 기기의 권한 화면과 마이크 녹음은 아직 직접 검증하지 않았습니다.
