# 말랑말랑 단어놀이 v1.2.1

## 마이크 권한을 허용해도 녹음이 거절되는 문제 수정

앱의 WebView 녹음 연결은 `RECORD_AUDIO`와 `MODIFY_AUDIO_SETTINGS` 권한을 함께 요구합니다. 기존 앱에는 두 번째 권한 선언이 빠져 있어, 사용자가 마이크를 허용해도 녹음 연결 전체가 거절될 수 있었습니다. 누락된 일반 권한을 추가했습니다. 이 권한에는 별도의 사용자 승인 창이 없습니다.

- 권한 확인 버튼이 Android 권한뿐 아니라 실제 녹음 연결도 확인하고 마이크를 즉시 해제합니다.
- 앱 권한 설정에서 돌아오면 상태를 다시 확인합니다.
- 허용되면 이전 차단 안내를 숨깁니다.
- 이미 허용된 상태에서 녹음 연결에 실패한 경우, 권한을 다시 허용하라고 반복 안내하지 않습니다.

**기존 앱을 삭제하지 않고 새 APK로 업데이트하세요.** 저장된 녹음을 유지하도록 같은 앱 ID와 서명 키를 사용합니다.

[웹 버전](https://qunix86b-ctrl.github.io/malang-word-play/?v=1.2.1)

WebView가 요구하는 권한과 앱 선언을 대조하는 회귀 테스트, 허용 후 상태 갱신 및 녹음 테스트를 추가했습니다. 실제 사용자의 갤럭시 기기에서 재현·해결 확인은 아직 하지 못했습니다.
